Agentic AI & Multi-Agent Orchestration at IBM

Data Scientist Intern · IBM AI & Automation · January–August 2026

During my internship at IBM, I worked on applied agentic-AI systems that connected tools, models, and cloud environments into larger orchestration workflows. My work spanned cross-cloud agent communication, authentication, deployment, debugging, and integrations for AI-assisted software-development workflows.

Cross-cloud agent orchestration

Connecting agents across cloud boundaries

I contributed to a proof of concept for orchestrating agents hosted across different cloud ecosystems. The goal was to let agents running in environments such as Azure AI Foundry and AWS Bedrock participate in a shared workflow rather than remaining isolated inside a single vendor stack.

My work focused heavily on the AWS side and on authentication. I helped enable agent communication through the A2A protocol, worked through cloud/security boundaries, and supported knowledge-base integration on Azure so agents could access the context required for their tasks.

Deploying a LangGraph agent

I containerized and deployed a LangGraph-based agent to Azure Container Apps, then tested service discovery, messaging, and Microsoft Entra ID authentication. This involved taking an agent from local development into a cloud-hosted environment where it could participate in the larger orchestration flow.

Agentic workflows for the software-development lifecycle

In the second half of the internship, I moved to a platform focused on orchestrating agents and automation across the software-development lifecycle. I contributed integrations that allowed coding-agent harnesses to participate in workflows for specification generation, code generation, and other development tasks.

Coding-agent integrations

I worked on end-to-end integrations for tools including Claude Code and Gemini, and later contributed to additional coding-assistant integrations. The focus was not just invoking a model, but fitting each agent into the platform's broader workflow, inputs, outputs, and execution lifecycle.

Platform debugging and integration work

I also contributed to platform-level testing and debugging, including reproducing workflow and database issues, validating autonomous-agent behaviour, and supporting integrations with external developer tools such as Bitbucket. This work required navigating an unfamiliar production codebase and tracing failures across multiple services.

What I learned

The internship gave me practical experience with a side of AI that is easy to miss in coursework: making multiple intelligent components actually work together reliably. I learned how much real-world agentic systems depend on authentication, APIs, deployment, observability, state, data access, and careful failure handling — not just model quality.

It also reinforced the kind of work I enjoy most: technical problem solving where AI is applied to a concrete operational or business goal, rather than treated as an isolated research object.
